## 🎯 درباره پروژه

**WOE (World of Entertainment)** یه وب‌اپلیکیشن **چندنفره آنلاین** است که به کاربران اجازه می‌ده از راه دور با دوستانشون بازی کنن و تست‌های شوخ‌طبعانه بدن! 🎉

- 🎮 **بازی‌های آنلاین:** XO، سنگ کاغذ قیچی، مار و پله، جرئت یا حقیقت، اونو
- 🧠 **تست‌های شخصیت:** فضول سنج، اسکنر شانس، هوش، ادایی، ترسو و...
- 👥 **چندنفره:** ۲ تا ۱۰ نفر از راه دور
- 🔐 **سیستم کاربری:** نام کاربری + رمز عبور + نام نمایشی
- 🏠 **اتاق‌های خصوصی:** ساخت اتاق با کد ۶ رقمی

## 🛠️ نصب و اجرا

### 📋 پیش‌نیازها
- Python 3.10+
- pip
- مرورگر مدرن

### 🔧 اجرای محلی

```bash
# ۱. کلون کردن ریپازیتوری
git clone https://github.com/amirhossin1395/WOE.git

# ۲. ورود به پوشه
cd WOE

# ۳. ساخت محیط مجازی (اختیاری)
python -m venv venv
venv\Scripts\activate  # ویندوز
# source venv/bin/activate  # لینوکس/مک

# ۴. نصب کتابخانه‌ها
pip install -r requirements.txt

# ۵. اجرا
python app.py

```
